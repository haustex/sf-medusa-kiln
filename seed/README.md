# Demo data (Tilde Goods)

`seed-kiln.ts` fills an empty Medusa backend with the fictional studio **Tilde Goods**: two regions (United States /
USD, Indonesia / IDR), a sales channel with a publishable key, a stock location with flat-rate shipping, six categories
and thirteen products priced in both currencies. It stops when the store already has a region.

```sh
cp seed/seed-kiln.ts <backend>/src/scripts/
mkdir -p <backend>/static/demo && cp seed/images/*.jpg <backend>/static/demo/
cd <backend> && npx medusa exec ./src/scripts/seed-kiln.ts   # prints the publishable key
```

Set `DEMO_IMAGE_BASE` when the images are served from somewhere other than the backend's `/static/demo`.

## Images

Every file in `images/` is generated by `demo-images.mjs` (flat still-life illustrations drawn with SVG and rendered
by sharp, 1200×1200 JPEG). No photographs, no third-party assets. Licence: **CC0 1.0** — use, change or replace them
freely. Regenerate with `node seed/demo-images.mjs`.
